Predicting Search Engagement Gaps: A Machine Learning Approach to CTR Opportunity Scoring

Abstract: This paper investigates click-through rate (CTR) anomalies across web content using search performance data. By analyzing position and impression distributions, we construct a machine learning pipeline to predict expected CTR per page. We evaluate a Random Forest regressor against a heuristic baseline model based on inverse rank position. The ML model significantly outperforms the baseline, enabling precise identification of underperforming pages. Finally, we provide evidence-backed recommendations to optimize search metadata and capture lost user engagement.

1. Introduction & Problem Statement

Web pages with high impression volumes often under-capture click engagement due to suboptimal titles, meta descriptions, or search intent misalignment. This study supports content optimization decisions by quantifying the gap between a page's actual CTR and its expected CTR based on positional dynamics.

2. Data Summary

Data was sourced from the public FlyRank Warehouse dataset. Data was aggregated at the page_id level for records exceeding 50 impressions to filter out noise. No raw private client parameters or Google internal signals were used.

3. Methodology

We designed a leakage-free validation pipeline using a standard 80/20 train-test split. Features included log-transformed total impressions and average SERP position. The target variable was set as actual_ctr.

5. Limitations & Honest Framing

The model relies exclusively on position and impression metrics without incorporating content intent or SERP feature layout changes (e.g., featured snippets), which may skew expected CTR in specific niches.

6. Ranked Recommendations

  • High Priority: Audit title tags and meta descriptions for pages where ctr_gap > 0.05 and total impressions exceed 1,000.
  • Medium Priority: Update structured data and rich snippet markup for secondary target queries.
  • Monitoring: Track post-refresh CTR movement over a 14-day observation window.
